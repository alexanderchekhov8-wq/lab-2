# Лабораторная работа №2: Уравнение переноса

Численное решение линейного уравнения переноса (одномерный случай) явными разностными схемами.

## Схемы
- «Против потока» (Upwind)
- FTCS (демонстрация неустойчивости)
- Лакса
- Лакса–Вендроффа

## Структура
- `solver.py` — ядро (класс `AdvectionSolver`, профили, шаги схем).
- `errors.py` — расчёт норм ошибок (L1, L2, L∞) и ширины FWHM.
- `cli.py` — командный интерфейс для визуализации и анимации.
- `test_solver.py` — автотесты (pytest).
- `requirements.txt` — зависимости.

## Установка и запуск
```bash
pip install -r requirements.txt
pytest test_solver.py -v
python cli.py --help
